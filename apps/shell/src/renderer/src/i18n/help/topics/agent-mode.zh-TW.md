# 代理程式模式

代理程式會把你選定的一個資料夾當成專案，在這個資料夾裡執行這台電腦上的 Claude Code 或 Codex。AI 會自己讀取資料夾裡的資料、建立新檔案、使用技能和指令碼，並修改在 GenOffice 中開啟的文件。需要用到大量資料的工作，可以交給它。

## 準備工作

- 已在**設定 ▸ AI**中連結的 Claude 訂閱或 ChatGPT 訂閱。連結方法請見「訂閱連線」主題。
- 一個放著你資料的資料夾。整個磁碟機、整個使用者主資料夾，以及存放登入資訊或應用程式資料的資料夾都不能選。

## 開始一個工作階段

1. 在首頁按一下**代理程式**卡片。代理程式視窗會另外開啟。
2. 按一下**選擇資料夾…**選定專案資料夾。最近用過的資料夾會列在**最近使用的資料夾**底下。
3. 在**程式**中選擇 Claude Code 或 Codex。尚未連結的程式無法選擇。
4. 在**何時詢問你**中選擇代理程式徵求許可的方式（見下表）。
5. 第一次使用時，請閱讀**開始之前**的說明，再按一下**我了解了**。
6. 按一下**開始**，寫下要做的事，再按一下**傳送**。

一個視窗就是一個工作階段。關閉視窗或按一下**停止**，工作階段就會結束，GenOffice 為它啟動的程式也會一起關閉。30 分鐘內什麼都沒傳送，工作階段也會結束。

## 代理程式如何詢問

| 選項                           | 直接進行                               | 先詢問                                           |
| ------------------------------ | -------------------------------------- | ------------------------------------------------ |
| **每次執行指令前詢問**（預設） | 讀寫專案資料夾中的檔案，修改開啟的文件 | 執行指令或指令碼，讀取專案資料夾以外的內容       |
| **寫入檔案和執行指令前都詢問** | 讀取專案資料夾中的檔案，修改開啟的文件 | 寫入檔案，執行指令或指令碼，讀取資料夾以外的內容 |
| **信任此專案**                 | 幾乎所有動作                           | 讀取專案資料夾以外的內容                         |

代理程式詢問時，視窗會顯示它想做什麼（完整的指令、檔案路徑）。請按一下**允許**或**拒絕**。

無論選哪一種方式，代理程式都不會：

- 覆寫在 GenOffice 分頁中開啟的文件檔案。開啟的文件是透過應用程式修改的，所以變更會立刻顯示在編輯器裡，也可以用編輯器的復原功能撤回。
- 在專案資料夾以外寫入。
- 碰觸 Claude 或 Codex 的登入資訊，或 GenOffice 的資料資料夾。

## Claude Code 與 Codex 的差別

- **Codex** 會在自己的隔離空間中執行指令，包括你允許的指令。它只能寫入專案資料夾，無法連上網際網路，也讀不到專案以外的個人檔案。工作階段開始時，GenOffice 會先檢查這台電腦上的隔離能否正常運作，不行的話就不會啟動。
- **Claude Code** 在 Windows 上無法隔離指令。你允許的指令可以存取整台電腦和網際網路。因此在**信任此專案**底下，會由 Claude Code 內建的審查模型代替你檢查每個動作。

別人傳給你的文件裡，可能藏有讓 AI 去做別的事的指示。如果資料夾裡的資料你不熟悉，請選擇會詢問的方式。

## 專案說明與技能

- 如果資料夾裡有 `CLAUDE.md` 或 `AGENTS.md`，其中的內容會當作指示交給代理程式。可以把每次都要遵守的事寫進去，例如語氣、用詞、要產生的文件格式。
- Claude Code 會拿到以下位置技能的副本：專案資料夾中的 `.claude/skills`，使用者主資料夾中的 `.ieumoffice/skills` 和 `.claude/skills`，以及已安裝的 Claude 外掛程式中的技能。可用的技能數量會顯示在提示工作階段已啟動的那一行下方。
- Codex 會自己讀取它的技能資料夾。
- 技能的指令碼所用的程式（例如 Python）必須已安裝在這台電腦上。

## 新檔案與開啟的文件

- 代理程式建立的新檔案會儲存在專案資料夾中。在進度記錄的那一行按一下**開啟**，就能在 GenOffice 分頁中開啟該檔案。
- 想讓它修改開啟的文件，請先在 GenOffice 中開啟這份文件，再在要求裡寫明文件名稱。
- 工作階段進行中開啟的文件，從下一則訊息起也可以修改。

## 隱私與用量

- 你對 AI 隱藏的內容，只有在應用程式為代理程式讀取 GenOffice 中開啟的文件時才會保持隱藏。代理程式直接從資料夾讀取的檔案會原樣傳送。
- 代理程式分成多個步驟工作，所以比 AI 面板消耗更多方案額度。額度用完時，要求會失敗；代理程式絕不會改用另一個 AI 或需要付費的連線。

## 發生問題時

| 視窗上顯示                                         | 該怎麼做                                 |
| -------------------------------------------------- | ---------------------------------------- |
| **未連線**                                         | 在**設定 ▸ AI**中登入那個程式。          |
| **無法使用此資料夾**                               | 選擇一個只放工作資料的資料夾。           |
| **在這台電腦上，Codex 無法開啟用來隔離指令的沙箱** | 更新 Windows，或改選 Claude Code。       |
| **方案額度已用完**                                 | 等額度重設後再傳送。                     |
| **程式版本過舊，無法使用代理程式模式**             | 更新那個程式，然後按一下**新工作階段**。 |
