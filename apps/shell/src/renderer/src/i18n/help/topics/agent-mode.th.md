# โหมดเอเจนต์

เอเจนต์จะใช้โฟลเดอร์หนึ่งโฟลเดอร์ที่คุณเลือกเป็นโปรเจกต์ แล้วเรียกใช้ Claude Code หรือ Codex ที่อยู่ในพีซีเครื่องนี้ในโฟลเดอร์นั้น AI จะอ่านเอกสารในโฟลเดอร์เอง สร้างไฟล์ใหม่ ใช้สกิลและสคริปต์ และแก้ไขเอกสารที่เปิดอยู่ใน GenOffice เหมาะกับงานที่ต้องอาศัยข้อมูลจำนวนมาก

## สิ่งที่ต้องมี

- การสมัครสมาชิก Claude หรือการสมัครสมาชิก ChatGPT ที่เชื่อมต่อไว้ใน **การตั้งค่า ▸ AI** วิธีเชื่อมต่ออยู่ในหัวข้อ "การเชื่อมต่อการสมัครสมาชิก"
- โฟลเดอร์ที่เก็บเอกสารของคุณไว้ เลือกทั้งไดรฟ์ ทั้งโฟลเดอร์หลักของผู้ใช้ หรือโฟลเดอร์ที่มีข้อมูลการลงชื่อเข้าใช้หรือข้อมูลแอปไม่ได้

## เริ่มเซสชัน

1. ที่หน้าแรก กดการ์ด **เอเจนต์** หน้าต่างเอเจนต์จะเปิดขึ้นแยกต่างหาก
2. กด **เลือกโฟลเดอร์…** เพื่อเลือกโฟลเดอร์โปรเจกต์ โฟลเดอร์ที่ใช้เมื่อเร็ว ๆ นี้จะแสดงอยู่ใต้ **โฟลเดอร์ล่าสุด**
3. ใน **โปรแกรม** ให้เลือก Claude Code หรือ Codex โปรแกรมที่ยังไม่ได้เชื่อมต่อจะเลือกไม่ได้
4. ใน **จะให้ถามคุณเมื่อใด** ให้เลือกวิธีที่เอเจนต์จะขออนุญาต (ดูตารางด้านล่าง)
5. ครั้งแรก ให้อ่าน **ก่อนเริ่มต้น** แล้วกด **เข้าใจแล้ว**
6. กด **เริ่ม** เขียนสิ่งที่ต้องการให้ทำ แล้วกด **ส่ง**

หนึ่งหน้าต่างคือหนึ่งเซสชัน การปิดหน้าต่างหรือกด **หยุด** จะจบเซสชัน และโปรแกรมที่ GenOffice เปิดไว้สำหรับเซสชันนั้นก็จะปิดไปด้วย เซสชันจะจบเองเช่นกันหากไม่ได้ส่งอะไรเลยเป็นเวลา 30 นาที

## เอเจนต์ถามอย่างไร

| ตัวเลือก                              | ทำได้ทันที                                                | ถามก่อน                                                   |
| ------------------------------------- | --------------------------------------------------------- | --------------------------------------------------------- |
| **ถามก่อนทุกคำสั่ง** (ค่าเริ่มต้น)    | อ่านและเขียนไฟล์ในโฟลเดอร์โปรเจกต์ แก้ไขเอกสารที่เปิดอยู่ | เรียกใช้คำสั่งหรือสคริปต์ อ่านข้อมูลนอกโฟลเดอร์โปรเจกต์   |
| **ถามก่อนเขียนไฟล์และเรียกใช้คำสั่ง** | อ่านไฟล์ในโฟลเดอร์โปรเจกต์ แก้ไขเอกสารที่เปิดอยู่         | เขียนไฟล์ เรียกใช้คำสั่งหรือสคริปต์ อ่านข้อมูลนอกโฟลเดอร์ |
| **เชื่อถือโปรเจกต์นี้**               | เกือบทุกอย่าง                                             | อ่านข้อมูลนอกโฟลเดอร์โปรเจกต์                             |

เมื่อเอเจนต์ถาม หน้าต่างจะแสดงสิ่งที่มันต้องการทำ (คำสั่งทั้งหมด พาธของไฟล์) ให้กด **อนุญาต** หรือ **ปฏิเสธ**

ไม่ว่าคุณจะเลือกแบบใด เอเจนต์จะไม่ทำสิ่งต่อไปนี้

- เขียนทับไฟล์ของเอกสารที่เปิดอยู่ในแท็บของ GenOffice เอกสารที่เปิดอยู่จะถูกแก้ไขผ่านแอป การเปลี่ยนแปลงจึงแสดงในโปรแกรมแก้ไขทันที และย้อนกลับได้ด้วยการเลิกทำของโปรแกรมแก้ไข
- เขียนไฟล์นอกโฟลเดอร์โปรเจกต์
- แตะต้องข้อมูลการลงชื่อเข้าใช้ของ Claude หรือ Codex หรือโฟลเดอร์ข้อมูลของ GenOffice

## Claude Code กับ Codex ต่างกันอย่างไร

- **Codex** เรียกใช้คำสั่งในพื้นที่แยกของตัวเอง รวมถึงคำสั่งที่คุณอนุญาตด้วย มันเขียนได้เฉพาะในโฟลเดอร์โปรเจกต์ อินเทอร์เน็ตถูกปิดกั้น และอ่านไฟล์ส่วนตัวของคุณที่อยู่นอกโปรเจกต์ไม่ได้ เมื่อเริ่มเซสชัน GenOffice จะตรวจสอบก่อนว่าการแยกพื้นที่นี้ใช้ได้บนพีซีเครื่องนี้ และถ้าใช้ไม่ได้ก็จะไม่เริ่ม
- **Claude Code** แยกพื้นที่ให้คำสั่งบน Windows ไม่ได้ คำสั่งที่คุณอนุญาตจึงเข้าถึงได้ทั้งพีซีและอินเทอร์เน็ต ด้วยเหตุนี้ ใน **เชื่อถือโปรเจกต์นี้** ตัวตรวจสอบของ Claude Code เองจะตรวจแต่ละการกระทำแทนคุณ

เอกสารที่คนอื่นส่งมาให้อาจมีคำสั่งแอบแฝงที่สั่งให้ AI ทำอย่างอื่น หากเป็นโฟลเดอร์ที่มีเอกสารที่คุณไม่รู้จัก ให้ใช้ตัวเลือกแบบที่ถามก่อน

## บันทึกของโปรเจกต์และสกิล

- หากโฟลเดอร์มี `CLAUDE.md` หรือ `AGENTS.md` เนื้อหาในไฟล์นั้นจะส่งให้เอเจนต์เป็นคำสั่ง ให้เขียนสิ่งที่ต้องยึดถือทุกครั้งไว้ เช่น น้ำเสียง คำศัพท์ และรูปแบบของเอกสารที่จะสร้าง
- Claude Code จะได้รับสำเนาของสกิลจากตำแหน่งเหล่านี้ ได้แก่ `.claude/skills` ในโฟลเดอร์โปรเจกต์ `.ieumoffice/skills` และ `.claude/skills` ในโฟลเดอร์หลักของคุณ และสกิลของปลั๊กอิน Claude ที่ติดตั้งไว้ จำนวนสกิลที่ใช้ได้จะแสดงใต้บรรทัดที่แจ้งว่าเซสชันเริ่มแล้ว
- Codex อ่านโฟลเดอร์สกิลของตัวเองเอง
- โปรแกรมที่สคริปต์ของสกิลใช้ (เช่น Python) ต้องติดตั้งไว้ในพีซีเครื่องนี้

## ไฟล์ใหม่และเอกสารที่เปิดอยู่

- ไฟล์ใหม่ที่เอเจนต์สร้างจะบันทึกไว้ในโฟลเดอร์โปรเจกต์ กด **เปิด** ที่บรรทัดนั้นในบันทึกความคืบหน้าเพื่อเปิดไฟล์ในแท็บของ GenOffice
- หากต้องการให้แก้ไขเอกสารที่เปิดอยู่ ให้เปิดเอกสารนั้นใน GenOffice ก่อน แล้วระบุชื่อเอกสารในคำขอ
- เอกสารที่เปิดระหว่างเซสชันจะแก้ไขได้ตั้งแต่ข้อความถัดไปของคุณ

## ความเป็นส่วนตัวและการใช้งาน

- ส่วนที่คุณซ่อนจาก AI จะยังถูกซ่อนอยู่ก็ต่อเมื่อแอปเป็นผู้อ่านเอกสารที่เปิดอยู่ใน GenOffice ให้เอเจนต์เท่านั้น ไฟล์ที่เอเจนต์อ่านจากโฟลเดอร์เองจะถูกส่งไปตามเดิม
- เอเจนต์ทำงานหลายขั้นตอน จึงใช้โควตาการสมัครสมาชิกมากกว่าแผง AI เมื่อโควตาหมด คำขอจะล้มเหลว เอเจนต์จะไม่ย้ายไปใช้ AI อื่นหรือการเชื่อมต่อที่มีค่าใช้จ่าย
