# Режим агента

Агент берёт одну выбранную вами папку как проект и запускает в ней Claude Code или Codex с этого компьютера. ИИ сам читает материалы в папке, создаёт новые файлы, пользуется навыками и скриптами и изменяет документы, открытые в GenOffice. Он подходит для работы, которая опирается на много материалов.

## Что нужно заранее

- Подписка Claude или подписка ChatGPT, подключённая в разделе **Настройки ▸ ИИ**. Как это сделать, рассказано в разделе «Подключение по подписке».
- Папка с вашими материалами. Нельзя выбрать весь диск, всю домашнюю папку, а также папки с данными входа или данными приложений.

## Как начать сеанс

1. На левой панели Главной нажмите **Агент**. Окно агента откроется отдельно.
2. Нажмите **Выбрать папку…** и укажите папку проекта. Папки, с которыми вы недавно работали, перечислены в списке **Недавние папки**.
3. В поле **Программа** выберите Claude Code или Codex. Неподключённую программу выбрать нельзя.
4. В поле **Когда спрашивать вас** выберите, как агент будет просить разрешения (см. таблицу ниже).
5. В первый раз прочитайте блок **Прежде чем начать** и нажмите **Понятно**.
6. Нажмите **Начать**, напишите, что нужно сделать, и нажмите **Отправить**.

Одно окно — это один сеанс. Если закрыть окно или нажать **Остановить**, сеанс завершится, а вместе с ним и программа, которую GenOffice для него запустил. Сеанс завершается и тогда, когда 30 минут ничего не отправлялось.

## Как агент спрашивает

| Вариант                                             | Делает сразу                                                          | Сначала спрашивает                                                  |
| --------------------------------------------------- | --------------------------------------------------------------------- | ------------------------------------------------------------------- |
| **Спрашивать перед каждой командой** (по умолчанию) | Чтение и запись файлов в папке проекта, изменение открытых документов | Запуск команды или скрипта, чтение за пределами папки проекта       |
| **Спрашивать перед записью и командами**            | Чтение файлов в папке проекта, изменение открытых документов          | Запись файла, запуск команды или скрипта, чтение за пределами папки |
| **Доверять этому проекту**                          | Почти всё                                                             | Чтение за пределами папки проекта                                   |

Когда агент спрашивает, окно показывает, что именно он хочет сделать (команду целиком, путь к файлу). Нажмите **Разрешить** или **Отклонить**.

Какой бы вариант вы ни выбрали, агент не станет:

- Перезаписывать файл документа, открытого во вкладке GenOffice. Открытые документы изменяются через приложение, поэтому правка сразу видна в редакторе и её можно отменить обычной отменой редактора.
- Записывать что-либо за пределами папки проекта.
- Трогать данные входа Claude или Codex и папку данных GenOffice.

## Claude Code и Codex

- **Codex** выполняет команды в своей изолированной среде, в том числе те, что вы разрешили. Записывать он может только в папку проекта, интернет для него закрыт, а ваши личные файлы за пределами проекта он прочитать не может. При запуске сеанса GenOffice сначала проверяет, работает ли эта изоляция на этом компьютере, и если нет, сеанс не начинается.
- **Claude Code** в Windows не умеет изолировать команды. Разрешённая вами команда может добраться до всего компьютера и до интернета. Поэтому в варианте **Доверять этому проекту** каждое действие вместо вас проверяет собственный проверяющий Claude Code.

В документе, который вам кто-то прислал, могут быть скрытые инструкции, которые велят ИИ сделать что-то другое. В папке с незнакомыми материалами выбирайте один из вариантов, где агент спрашивает.

## Заметки проекта и навыки

- Если в папке есть `CLAUDE.md` или `AGENTS.md`, их содержимое передаётся агенту как инструкции. Запишите туда то, что должно соблюдаться каждый раз: тон, термины, формат документов, которые нужно сделать.
- Claude Code получает копию навыков из этих мест: `.claude/skills` в папке проекта, `.ieumoffice/skills` и `.claude/skills` в домашней папке, а также навыки установленных плагинов Claude. Число доступных навыков показано под строкой о запуске сеанса.
- Codex сам читает собственную папку навыков.
- Программы, которыми пользуются скрипты навыка (Python и другие), должны быть установлены на этом компьютере.

## Новые файлы и открытые документы

- Новые файлы, которые создаёт агент, сохраняются в папке проекта. Нажмите **Открыть** в этой строке журнала хода работы, чтобы открыть файл во вкладке GenOffice.
- Чтобы агент изменил открытый документ, сначала откройте его в GenOffice и назовите его в своём запросе.
- Документ, открытый во время сеанса, можно изменять начиная со следующего сообщения.

## Конфиденциальность и расход лимита

- Скрытое от ИИ остаётся скрытым, только когда приложение само читает для агента документ, открытый в GenOffice. Файлы, которые агент читает из папки сам, отправляются как есть.
- Агент работает во много шагов, поэтому расходует больше лимита подписки, чем панель ИИ. Когда лимит исчерпан, запрос завершается ошибкой; агент никогда не переключается на другой ИИ или на платное подключение.

## Если что-то пошло не так

| Что написано в окне                                     | Что делать                                               |
| ------------------------------------------------------- | -------------------------------------------------------- |
| **Нет подключения**                                     | Войдите в эту программу в разделе **Настройки ▸ ИИ**.    |
| **Эту папку нельзя использовать**                       | Выберите папку, в которой только ваши рабочие материалы. |
| **Codex не может открыть на этом компьютере песочницу** | Обновите Windows или выберите Claude Code.               |
| **Лимит подписки исчерпан**                             | Отправьте запрос снова, когда лимит обновится.           |
| **Программа слишком старая для режима агента**          | Обновите эту программу, затем нажмите **Новый сеанс**.   |
