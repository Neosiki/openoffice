# 智能体模式

智能体把你选定的一个文件夹当作项目，在这个文件夹里运行这台电脑上的 Claude Code 或 Codex。AI 会自己读取文件夹里的资料、创建新文件、使用技能和脚本，并修改在 GenOffice 中打开的文档。需要用到大量资料的工作，可以交给它。

## 准备工作

- 已在**设置 ▸ AI**中连接的 Claude 订阅或 ChatGPT 订阅。连接方法见“订阅连接”主题。
- 一个放着你资料的文件夹。整个驱动器、整个用户主文件夹，以及存放登录信息或应用数据的文件夹都不能选。

## 开始一次会话

1. 在主屏上点**智能体**卡片。智能体窗口会单独打开。
2. 点**选择文件夹…**选定项目文件夹。最近用过的文件夹会列在**最近的文件夹**下。
3. 在**程序**中选择 Claude Code 或 Codex。未连接的程序不能选。
4. 在**何时询问你**中选择智能体征求许可的方式（见下表）。
5. 第一次使用时，阅读**开始之前**的说明，然后点**我已了解**。
6. 点**开始**，写下要做的事，再点**发送**。

一个窗口就是一次会话。关闭窗口或点**停止**，会话就会结束，GenOffice 为它启动的程序也会一起关闭。30 分钟内什么都没发送，会话也会结束。

## 智能体如何询问

| 选项                           | 直接进行                               | 先询问                                         |
| ------------------------------ | -------------------------------------- | ---------------------------------------------- |
| **每次运行命令前询问**（默认） | 读写项目文件夹中的文件，修改打开的文档 | 运行命令或脚本，读取项目文件夹以外的内容       |
| **写入文件和运行命令前都询问** | 读取项目文件夹中的文件，修改打开的文档 | 写入文件，运行命令或脚本，读取文件夹以外的内容 |
| **信任此项目**                 | 几乎所有操作                           | 读取项目文件夹以外的内容                       |

智能体询问时，窗口会显示它要做什么（完整的命令、文件路径）。点**允许**或**拒绝**。

无论选哪种方式，智能体都不会：

- 覆盖在 GenOffice 标签页中打开的文档的文件。打开的文档是通过应用来修改的，所以改动会立刻显示在编辑器里，也可以用编辑器的撤销功能撤回。
- 在项目文件夹以外写入。
- 碰 Claude 或 Codex 的登录信息，或 GenOffice 的数据文件夹。

## Claude Code 与 Codex 的区别

- **Codex** 在自己的隔离空间中运行命令，包括你允许的命令。它只能写入项目文件夹，无法访问互联网，也读不到项目以外的个人文件。会话开始时，GenOffice 会先检查这台电脑上的隔离能否正常工作，不能的话就不会启动。
- **Claude Code** 在 Windows 上无法隔离命令。你允许的命令可以访问整台电脑和互联网。因此在**信任此项目**下，由 Claude Code 自带的审查模型代替你检查每个操作。

别人发给你的文档里，可能藏有让 AI 去做别的事的指令。如果文件夹里的资料你不了解，请选择会询问的方式。

## 项目说明与技能

- 如果文件夹里有 `CLAUDE.md` 或 `AGENTS.md`，其中的内容会作为指令交给智能体。可以把每次都要遵守的东西写进去，比如语气、用词、要生成的文档格式。
- Claude Code 会拿到以下位置技能的副本：项目文件夹中的 `.claude/skills`，用户主文件夹中的 `.ieumoffice/skills` 和 `.claude/skills`，以及已安装的 Claude 插件中的技能。可用的技能数会显示在提示会话已启动的那一行下面。
- Codex 会自己读取它的技能文件夹。
- 技能的脚本所用的程序（如 Python）必须已安装在这台电脑上。

## 新文件与打开的文档

- 智能体创建的新文件保存在项目文件夹中。在进度记录的那一行点**打开**，就能在 GenOffice 标签页中打开该文件。
- 想让它修改打开的文档，先在 GenOffice 中打开这个文档，再在请求里写明文档名称。
- 会话进行中打开的文档，从下一条消息起也可以修改。

## 隐私与用量

- 你对 AI 隐藏的内容，只有在应用为智能体读取 GenOffice 中打开的文档时才会保持隐藏。智能体直接从文件夹读取的文件会原样发送。
- 智能体分多个步骤工作，所以比 AI 面板消耗更多订阅额度。额度用完时，请求会失败；智能体绝不会换到另一个 AI 或要付费的连接。

## 出现问题时

| 窗口上显示                                         | 该怎么做                           |
| -------------------------------------------------- | ---------------------------------- |
| **未连接**                                         | 在**设置 ▸ AI**中登录那个程序。    |
| **无法使用此文件夹**                               | 选择一个只放工作资料的文件夹。     |
| **在这台电脑上，Codex 无法打开用于隔离命令的沙盒** | 更新 Windows，或改选 Claude Code。 |
| **订阅额度已用完**                                 | 等额度重置后再发送。               |
| **程序版本过旧，无法使用智能体模式**               | 更新那个程序，然后点**新会话**。   |
