# מצב סוכן

הסוכן מתייחס לתיקייה אחת שבחרתם כפרויקט, ומפעיל בה את Claude Code או Codex מהמחשב הזה. ה-AI קורא בעצמו את החומרים שבתיקייה, יוצר קבצים חדשים, משתמש במיומנויות ובסקריפטים, ועורך את המסמכים הפתוחים ב-GenOffice. כדאי להשתמש בו לעבודה שנשענת על הרבה חומר.

## לפני שמתחילים

- מינוי Claude או מינוי ChatGPT שמחובר תחת **הגדרות ▸ AI**. הנושא "חיבור מינוי" מסביר איך.
- תיקייה שבה נמצאים החומרים שלכם. אי אפשר לבחור כונן שלם, את כל תיקיית הבית שלכם, או תיקיות של נתוני התחברות או נתוני אפליקציות.

## התחלת סשן

1. בבית, לחצו על הכרטיס **סוכן**. חלון הסוכן נפתח בנפרד.
2. לחצו **בחירת תיקייה…** כדי לבחור את תיקיית הפרויקט. תיקיות שהשתמשתם בהן לאחרונה מופיעות תחת **תיקיות אחרונות**.
3. תחת **תוכנה**, בחרו Claude Code או Codex. אי אפשר לבחור תוכנה שאינה מחוברת.
4. תחת **מתי לשאול אותך**, בחרו איך הסוכן יבקש רשות (ראו בטבלה שלהלן).
5. בפעם הראשונה, קראו את **לפני שמתחילים** ולחצו **הבנתי**.
6. לחצו **התחלה**, כתבו מה אתם רוצים שייעשה, ולחצו **שליחה**.

חלון אחד הוא סשן אחד. סגירת החלון או לחיצה על **עצירה** מסיימות את הסשן, וגם התוכנה ש-GenOffice הפעילה עבורו נסגרת. סשן מסתיים גם אחרי 30 דקות שבהן לא נשלח דבר.

## איך הסוכן שואל

| אפשרות                               | מתבצע מיד                                                  | נשאל קודם                                            |
| ------------------------------------ | ---------------------------------------------------------- | ---------------------------------------------------- |
| **לשאול לפני כל פקודה** (ברירת מחדל) | קריאה וכתיבה של קבצים בתיקיית הפרויקט, עריכת מסמכים פתוחים | הרצת פקודה או סקריפט, קריאה מחוץ לתיקיית הפרויקט     |
| **לשאול לפני כתיבה ופקודות**         | קריאת קבצים בתיקיית הפרויקט, עריכת מסמכים פתוחים           | כתיבת קובץ, הרצת פקודה או סקריפט, קריאה מחוץ לתיקייה |
| **לסמוך על הפרויקט הזה**             | כמעט הכול                                                  | קריאה מחוץ לתיקיית הפרויקט                           |

כשהסוכן שואל, החלון מציג מה הוא רוצה לעשות (הפקודה המלאה, נתיב הקובץ). לחצו **אישור** או **דחייה**.

לא משנה מה תבחרו, הסוכן לא:

- דורס את הקובץ של מסמך שפתוח בכרטיסייה של GenOffice. מסמכים פתוחים נערכים דרך האפליקציה, כך שהשינוי מופיע מיד בעורך ואפשר לבטל אותו בפעולת הביטול של העורך.
- כותב מחוץ לתיקיית הפרויקט.
- נוגע בנתוני ההתחברות של Claude או Codex, או בתיקיית הנתונים של GenOffice.

## Claude Code ו-Codex

- **Codex** מריץ פקודות במרחב המבודד שלו, כולל פקודות שאישרתם. הוא יכול לכתוב רק בתיקיית הפרויקט, האינטרנט חסום בפניו, והוא לא יכול לקרוא את הקבצים האישיים שלכם מחוץ לפרויקט. כשסשן מתחיל, GenOffice בודקת קודם שהבידוד הזה עובד במחשב הזה, ואם לא, הסשן לא מתחיל.
- **Claude Code** לא יכול לבודד פקודות ב-Windows. פקודה שאישרתם יכולה להגיע לכל המחשב ולאינטרנט. לכן, באפשרות **לסמוך על הפרויקט הזה**, הבודק המובנה של Claude Code בודק כל פעולה במקומכם.

מסמך שמישהו שלח לכם עלול להכיל הוראות נסתרות שאומרות ל-AI לעשות משהו אחר. בתיקייה עם חומרים שאינכם מכירים, השתמשו באחת האפשרויות ששואלות.

## הערות פרויקט ומיומנויות

- אם בתיקייה יש `CLAUDE.md` או `AGENTS.md`, התוכן שלו נמסר לסוכן כהוראות. כתבו בו את מה שצריך להישמר בכל פעם: סגנון, מונחים, תבנית המסמכים שיש ליצור.
- Claude Code מקבל עותק של המיומנויות מהמקומות האלה: `.claude/skills` בתיקיית הפרויקט, `.ieumoffice/skills` ו-`.claude/skills` בתיקיית הבית שלכם, והמיומנויות של תוספי Claude המותקנים. מספר המיומנויות הזמינות מופיע מתחת לשורה שאומרת שהסשן התחיל.
- Codex קורא את תיקיית המיומנויות שלו בעצמו.
- תוכנות שהסקריפטים של מיומנות משתמשים בהן (Python וכדומה) צריכות להיות מותקנות במחשב הזה.

## קבצים חדשים ומסמכים פתוחים

- קבצים חדשים שהסוכן יוצר נשמרים בתיקיית הפרויקט. לחצו **פתיחה** בשורה המתאימה ביומן ההתקדמות כדי לפתוח את הקובץ בכרטיסייה של GenOffice.
- כדי שמסמך פתוח ייערך, פתחו אותו קודם ב-GenOffice וציינו את שמו בבקשה.
- מסמך שתפתחו במהלך סשן אפשר לערוך החל מההודעה הבאה שלכם.

## פרטיות ושימוש

- מה שהסתרתם מה-AI נשאר מוסתר רק כשהאפליקציה קוראת עבור הסוכן מסמך שפתוח ב-GenOffice. קבצים שהסוכן קורא בעצמו מהתיקייה נשלחים כפי שהם.
- הסוכן עובד בצעדים רבים, ולכן הוא מנצל יותר ממכסת המנוי שלכם מאשר חלונית ה-AI. כשהמכסה נגמרת, הבקשה נכשלת; הסוכן לעולם לא עובר ל-AI אחר או לחיבור שגובה תשלום.
