# Mac 베타 시험 안내

이음오피스 Mac판을 먼저 써 보고 알려 주실 분들을 위한 안내입니다. 개발자에게 Mac이 없어서, 여러분이 확인해 주신 것이 곧 "Mac에서 된다"의 근거가 됩니다. 고맙습니다.

## 먼저 알아 두실 것

| 항목            | 내용                                                                                                                                    |
| --------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| 쓸 수 있는 Mac  | **Apple Silicon Mac(M1 이후)** 만 됩니다. 사과 메뉴 → "이 Mac에 관하여"에서 "칩"이 `Apple M…`이면 됩니다. Intel Mac은 지원하지 않습니다 |
| macOS 버전      | macOS 12(Monterey) 이상                                                                                                                 |
| 처음 열 때 경고 | 앱에 Apple 개발자 서명이 없어서 macOS가 "확인할 수 없다"고 경고합니다. 아래 순서대로 한 번만 허용하면 됩니다                            |
| 업데이트        | Mac판은 **스스로 업데이트하지 않습니다.** 새 버전이 나오면 앱이 알려 주고 다운로드 페이지를 엽니다. 새 dmg를 받아 덮어 설치합니다       |
| AI              | 이미 쓰고 계신 Claude 또는 ChatGPT(Codex) 구독으로 돌아갑니다. 시험할 때도 **여러분의 사용 한도를 씁니다.** 몇 번만 해 보시면 됩니다    |

## 1. 설치하기

1. [릴리스 페이지](https://github.com/pblsketch/openoffice/releases)에서 `IeumOffice-<버전>-arm64.dmg`를 받습니다.
2. 받은 dmg를 두 번 눌러 열고, **IeumOffice** 아이콘을 **Applications(응용 프로그램)** 폴더로 끌어다 놓습니다.
3. 응용 프로그램 폴더에서 IeumOffice를 엽니다. "Apple은 'IeumOffice'에 악성 코드가 없음을 확인할 수 없습니다" 같은 창이 뜨면 **완료**를 누릅니다.
4. **시스템 설정 → 개인정보 보호 및 보안**을 열고 아래로 내리면 "IeumOffice이(가) 차단되었습니다"라는 줄이 있습니다. 옆의 **그래도 열기**를 누르고 Mac 암호를 넣습니다.
5. 다시 뜨는 창에서 **열기**를 누릅니다. 이후로는 경고 없이 열립니다.

**"손상되었기 때문에 열 수 없습니다"라고 나오면** 휴지통으로 옮기지 말고, 터미널 앱을 열어 아래 한 줄을 붙여 넣고 Enter를 누른 뒤 다시 엽니다. 인터넷에서 받은 파일에 붙는 표시를 지우는 명령입니다.

```sh
xattr -dr com.apple.quarantine /Applications/IeumOffice.app
```

> 확인 필요: 위 창의 문구와 메뉴 이름은 macOS 버전마다 조금 다를 수 있습니다. 실제 문구가 다르면 알려 주세요. 안내를 고치겠습니다.

## 2. AI 연결하기

앱은 Mac에 설치된 **Claude Code** 또는 **Codex** 프로그램을 실행해서 AI를 씁니다. 둘 중 하나만 있으면 됩니다.

1. 앱의 AI 연결 카드에 "설치되어 있지 않음"이 보이면 **공식 설치 안내** 링크를 눌러 그 회사의 안내대로 설치합니다. (Windows판과 달리 Mac판에는 "설치" 버튼이 없습니다.)
2. 설치한 뒤 앱의 카드에서 **로그인**을 누르면 브라우저가 열립니다. 그 회사의 페이지에서 로그인하고 허용하면 카드가 "연결됨"으로 바뀝니다.
3. **브라우저 로그인이 끝나지 않을 때**(브라우저가 코드를 보여 주며 붙여 넣으라고 할 때 등): 터미널 앱을 열고 Claude는 `claude auth login`, Codex는 `codex login`을 직접 실행해 안내대로 로그인합니다. 끝나면 앱으로 돌아오면 됩니다.

## 3. 확인해 주실 것

다 하지 않으셔도 됩니다. 해 본 것만 알려 주세요. **"됐다"는 보고도 아주 중요합니다.**

| 번호 | 확인할 것                        | 하는 방법                                                                                           | 이렇게 되면 정상                                                  |
| ---- | -------------------------------- | --------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| 1    | 설치와 첫 실행                   | 위 1번 순서                                                                                         | 앱이 열리고 홈 화면이 보인다                                      |
| 2    | 워드·엑셀·파워포인트             | `.docx`·`.xlsx`·`.pptx` 파일을 하나씩 열어 글자를 고치고 저장                                       | 다시 열면 고친 내용이 그대로다. Microsoft Office에서도 열린다     |
| 3    | PDF·마크다운·HTML                | 파일을 열어 보고, 마크다운·HTML은 고쳐서 저장                                                       | 내용이 깨지지 않는다                                              |
| 4    | 한글 문서                        | `.hwp`·`.hwpx` 파일을 열어 보고 고쳐서 저장                                                         | 글꼴이 크게 어긋나지 않는다. 한컴오피스에서 다시 열린다           |
| 5    | 마인드맵                         | `.xmind` 파일을 열어 주제를 하나 더하고 저장                                                        | XMind에서 다시 열린다                                             |
| 6    | Windows와 주고받기               | Windows 사용자에게서 받은 파일을 열고, Mac에서 저장한 파일을 Windows에서 열어 보기                  | 양쪽에서 똑같이 보인다                                            |
| 7    | AI 연결                          | 위 2번 순서                                                                                         | 카드가 "연결됨"이 된다                                            |
| 8    | AI로 문서 고치기                 | 워드 문서를 열고 AI 창에 "첫 문단 뒤에 한 문단을 더 써 줘" 같은 요청을 **한 번**                    | 문단이 **한 번만** 들어간다                                       |
| 9    | AI 중단                          | 요청을 보낸 직후 중단 버튼                                                                          | 바로 멈춘다                                                       |
| 10   | 앱을 끈 뒤 남는 프로그램         | AI가 답하는 도중에 앱을 끄고(⌘Q), **활동 모니터**에서 `claude`나 `codex`를 검색                     | 앱이 띄운 것이 남아 있지 않다(따로 터미널에서 쓰던 것은 상관없음) |
| 11   | 스캔 PDF 글자 인식               | 사진으로 찍은 문서 PDF를 워드로 변환                                                                | 글자가 글자로 들어온다(그림으로만 들어오지 않는다)                |
| 12   | 기본 앱으로 정하기               | 설정에서 이음오피스를 기본 앱으로 정하는 항목, 또는 Finder에서 파일을 오른쪽 클릭 → "다음으로 열기" | 파일을 두 번 누르면 이음오피스로 열린다                           |
| 13   | 터미널 명령어(쓰시는 분만)       | 설정의 연동 항목에서 터미널 명령어를 설치하고 터미널에서 `ieumoffice --version`                     | 버전이 나온다                                                     |
| 14   | 새 버전 알림(다음 버전이 나오면) | 새 버전이 나온 뒤 앱을 켜고 잠시 기다리거나 도움말 → 업데이트 확인                                  | "다운로드 페이지에서 새 버전을 받아 설치해 달라"는 창이 뜬다      |

## 4. 알려 주시는 방법

[GitHub 이슈](https://github.com/pblsketch/openoffice/issues/new/choose)에 남겨 주시거나, 개발자에게 직접 전해 주세요. 아래를 함께 적어 주시면 큰 도움이 됩니다.

| 적을 것         | 예                                                |
| --------------- | ------------------------------------------------- |
| Mac 모델과 칩   | MacBook Air, M2                                   |
| macOS 버전      | macOS 15.5                                        |
| 이음오피스 버전 | 설정 → 정보에 보이는 번호                         |
| 확인한 번호     | 위 표의 번호(예: 2, 7, 8 됨 / 4 안 됨)            |
| 안 된 경우      | 무엇을 눌렀고 무엇이 보였는지, 가능하면 화면 캡처 |

문서 내용이나 계정 이메일이 화면 캡처에 보이지 않게 가려 주세요.
