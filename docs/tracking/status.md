## 남은 것 (순서대로)

1. **첫 릴리스 내기.** 그 전에 저장소 주인이 Anthropic 상업 약관에 동의하고, GitHub 저장소에서 비공개 취약점 신고를 켠다. 첫 릴리스에서 실제 자동 업데이트(내려받기 → 재시작 → 설치)를 확인하고, 릴리스 절차 문서의 "확인 필요" 표시와 소개 문서의 해당 한계 문장을 지운다. 릴리스 전에 설정의 로그아웃과 다른 계정으로 로그인 버튼을 실제로 한 번 눌러 확인한다.
2. **도움말 그림 다시 찍기.** 없어진 화면을 담은 그림 10장을 본문에서 빼 둔 상태다. 빌드된 앱으로 다시 찍고 21개 언어 본문에 다시 넣는다. 구독 연결 주제에는 그림이 아직 없다.
3. **마인드맵과 새 문서 만들기의 마지막 확인.** 이 앱이 저장한 지도(새 파일, 제목을 고친 것, 가지를 옮기고 지운 것, 테마를 고른 것, 미리보기 그림이 없는 것)가 XMind 웹 앱에서 열리는지 본다. 실제 구독으로 여섯 가지(지도 편집, 문서 → 지도, 지도 → PPT, 워드·PDF → PPT, 지도 → HTML, 긴 자료 → PPT)를 한 번씩 확인하고, 긴 자료로 만든 PPT가 충분한지는 사용자가 판단한다. 설치본에서 `.xmind`를 열어 고치고 저장한다. 브랜드 그림, 테마 96가지의 고르는 화면, 주요 화면을 사용자가 승인한다.
4. **가리기의 남은 길.** 워드 문서(다른 파일로 읽을 때 닫힌 쪽으로 실패하는 안이 제안됨), PPT 편집기와 마크다운 편집기에서 표시 없이 저장되는 두 경우, `.txt`·`.json`으로 저장한 마크다운, 터미널 명령어와 MCP의 읽기. 앞의 넷은 사용자의 결정을 기다린다(`findings.md`).
5. **Codex 구독으로 이미지 만들기.** 로그인 파일을 건드리지 않는 방법으로만 넣는다. 이미지 도구가 있는 요금제의 계정으로 다시 확인해야 한다.
6. **PDF 새 기능의 확인 마무리.** 빌드한 앱에서 확인한 것: 변환 창의 범위 오류, Markdown 변환 뒤 탭 열기, EPUB 저장과 폴더 열기, 그림만 내보내기, AI 페이지 읽기의 페이지 고르기·요금 안내가 있는 확인 창·검색의 "AI로 읽은 글에서 찾음"·이어하기 제안, 번역 창(아랍어에서 PDF 형식 막힘)·확인 창·지금까지 반영해 내보내기. 실제 구독(Claude, haiku)으로도 확인했다: 스캔 페이지 1쪽 AI 읽기와 검색, 2쪽 문서의 한국어 번역(Markdown과 PDF, 7개 블록 모두 번역), 번역 멈추기와 앱 종료 뒤 앱이 띄운 `claude`가 남지 않음. 남은 것: 변환 중 취소를 앱에서 직접 해 보기(지금은 단위 테스트로만 확인), 멈추기 직후 몇 초 안에 `claude`가 끝나는지 재 보기(확인 때는 약 40초 간격으로만 봤다).
7. **PDF 새 기능의 남은 것.**
   - 로컬 OCR 모델로 페이지 읽기(pdf-craft의 DeepSeek OCR 같은 것). 이번 범위에서 뺐다.
   - EPUB 열기와 번역. 지금은 EPUB을 쓰기만 한다.
   - 워드 변환의 수식(OMML). 문서 엔진(`docx-engine`)을 고쳐야 해서 따로 승인이 필요하다.
   - 대역 PDF. 대역은 Markdown·EPUB에만 있다.
   - 새 기능(변환, AI 페이지 읽기, 번역, 보관소)의 앱 안 도움말 주제.
   - 다른 이름으로 저장한 사본과 영구 가림 사본이 보관된 결과를 옮겨 받지 못한다. 앱 안 "저장"만 옮긴다.
   - 라틴 문자 문서의 기본 목표 언어. 문서 언어를 문자 체계로만 추정해 프랑스어·독일어 문서도 영어로 읽고, 화면 언어가 영어면 기본값이 영어 문서와 같아진다. 번역 창에서 바꿀 수 있다.
   - 아랍어·히브리어·힌디어 번역 PDF. 번역문을 PDF에 배치하지 못해 고를 수 없게 해 두었다. Markdown·EPUB은 된다.
   - 페이지 범위를 고른 번역 PDF가 모든 페이지를 담는다. 고른 페이지만 번역되고 나머지는 원본 그대로다.
8. 그 밖에 미뤄 둔 것: 유료 코드 서명, macOS·Linux 배포, 한글 글꼴을 자체 저장소로 내려받게 하는 것. 디자인 템플릿 쪽에서는 이미 있는 슬라이드를 다른 템플릿으로 바꾸기(다시 그리면 발표자 메모·메모·전환·링크·개체 틀이 사라지고, 넣어 둔 그림을 옮기지 못하고, 실행 취소 기록이 50단계라 되돌리기도 어렵다), 원본의 나머지 템플릿 22개, 앱 안 도움말, 마크다운·HTML·PDF 편집기의 템플릿 글꼴.
9. 마인드맵과 새 문서 만들기의 다음 단계: XMind 테마 읽기, 표식 붙이기, 경계 그리기, 그림 넣기, 개요 보기, 예전 XMind 8 형식 가져오기, 워드·마크다운으로 만들기, 긴 자료의 품질 개선, 터미널 명령어의 `.xmind`, 마인드맵 도움말(21개 언어), 다시 만들기.

## 막힌 것

첫 릴리스는 저장소 주인이 해야 하는 두 가지를 기다린다. Anthropic 상업 약관 동의, GitHub 저장소의 비공개 취약점 신고 켜기. 코드 작업을 막는 것은 없다.
