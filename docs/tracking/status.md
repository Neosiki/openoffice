## 남은 것 (순서대로)

1. **첫 릴리스 내기.** 그 전에 저장소 주인이 Anthropic 상업 약관에 동의하고, GitHub 저장소에서 비공개 취약점 신고를 켠다. 첫 릴리스에서 실제 자동 업데이트(내려받기 → 재시작 → 설치)를 확인하고, 릴리스 절차 문서의 "확인 필요" 표시와 소개 문서의 해당 한계 문장을 지운다. 릴리스 전에 설정의 로그아웃과 다른 계정으로 로그인 버튼을 실제로 한 번 눌러 확인한다.
2. **도움말 그림 다시 찍기.** 없어진 화면을 담은 그림 10장을 본문에서 빼 둔 상태다. 빌드된 앱으로 다시 찍고 21개 언어 본문에 다시 넣는다. 구독 연결 주제에는 그림이 아직 없다.
3. **마인드맵 문서.** `.xmind` 파일을 직접 열고 고쳐서 같은 파일로 저장한다. 이 편집기가 지원하지 않는 요소도 저장할 때 잃지 않는다. 편집 화면은 MIT 라이선스 오픈소스를 쓴다(후보: simple-mind-map, mind-elixir. 선택은 시작할 때). XMind의 이름·로고·테마·아이콘·코드는 쓰지 않는다.
4. **문서 묶음 기반 생성.** 관련 문서들을 한 묶음으로 두고, AI가 묶음 안의 문서를 참고해 새 문서를 만든다(워드·PDF → PPT, 마인드맵 → PPT·HTML). 이미 있는 "프로젝트"와 "지식 자료"가 출발점이 될 수 있다.
5. **Codex 구독으로 이미지 만들기.** 로그인 파일을 건드리지 않는 방법으로만 넣는다. 이미지 도구가 있는 요금제의 계정으로 다시 확인해야 한다.
6. 그 밖에 미뤄 둔 것: 유료 코드 서명, macOS·Linux 배포, 한글 글꼴을 자체 저장소로 내려받게 하는 것. 디자인 템플릿 쪽에서는 이미 있는 슬라이드를 다른 템플릿으로 바꾸기(다시 그리면 발표자 메모·메모·전환·링크·개체 틀이 사라지고, 넣어 둔 그림을 옮기지 못하고, 실행 취소 기록이 50단계라 되돌리기도 어렵다), 원본의 나머지 템플릿 22개, 앱 안 도움말, 마크다운·HTML·PDF 편집기의 템플릿 글꼴.

## 막힌 것

첫 릴리스는 저장소 주인이 해야 하는 두 가지를 기다린다. Anthropic 상업 약관 동의, GitHub 저장소의 비공개 취약점 신고 켜기. 코드 작업을 막는 것은 없다.
